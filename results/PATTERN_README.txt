坐标与扫描范围
三块直角等腰三角形板分别位于 xy、yz、zx 平面，公共内顶点为原点，
三条内棱沿 +x、+y、+z，各长 43.6 mm；开口 x+y+z=a 未封闭。
全局观测方向 s=[cos(el)cos(az), cos(el)sin(az), sin(el)]。
二维图：az=1:0.5:89°，el=1:0.5:89°，177×177=31329 个方向；HH/VV同时计算。
正对开口的全局坐标：az=45°，el=35.26438968°。
原始固定角切面：az=0.25:0.25:89.75°、el固定正向值；或az固定45°、
el=0.25:0.25:89.75°，并额外包含精确正向俯仰点。
本模型只计算 s_x,s_y,s_z>0 的第一卦限，没有计算背面、完整球面或精确
坐标边界处的掠射情况。白边/未画区域不是零 RCS。

正向局部角度的定义
forward=[1,1,1]/sqrt(3)
horizontal=[-1,1,0]/sqrt(2)
vertical=[-1,-1,2]/sqrt(6)
s=cos(beta)cos(alpha)*forward + cos(beta)sin(alpha)*horizontal + sin(beta)*vertical。
局部方位切面 beta=0，alpha=-39:0.25:39°；局部俯仰切面 alpha=0。
“全局方位角减45°”不等于这个局部方位角。原始全局固定俯仰切面的
HH −3 dB 宽度为47.72128°，不能与局部方位宽度38.89567°混用。

计算方法
沿用此前的理想 PEC 几何光学反射和矢量 Huygens 出射口积分模型。
为避免广角扫描中入射射线管投影权重 1/(n dot d_out) 的采样病态性，
最终版本在出射口均匀取样，并对每个可能的反射分支做反向可见性判断。
这是相同场积分的稳定采样方式，没有用理论 RCS 方向函数替代数值结果。

正交板面允许精确求反射事件时间。若某分支反射的坐标轴集合为 B，则
从出射口反向传播时，最后一个必需反射的时间为 max(r_j/s_j,j in B)，
经过全部必需反射后再次离开孔口的时间为 2*sum(r_j,j in B)/sum(s)。
前者小于后者时，该分支可见。这个快速判断已与逐步求交的原始射线程序
做了独立对照。所有金属平面通过原点，故反射波相位满足
d_in dot r_in + L = d_out dot r_out；据此保留完整的相干相位积分。
积分包含所有可见的一次、二次、三次反射分支。

二维图每个角度用 384^2=147456 个出射口采样点；切面用
768^2=589824 个采样点。每个点可能对应多个出射分支，最多4个。
因此“孔口采样点数”不能简单视为所有分支的追踪射线总数。
采样加密验证使用 1536^2=2359296 个孔口点。

数值核验与本次修正
最终的97个抽查角度，包括接近掠射和原伪峰角度，384→1536加密后：
- 位于正向值以下3 dB范围的抽查点，最大变化0.015640 dB；
- 位于正向值以下10 dB范围的抽查点，最大变化0.016390 dB；
- 全部抽查点的最大变化0.077857 dB。
额外核验二维图中最高的12个候选角度，最大变化0.011684 dB。
这些是有限样点的数值积分一致性，不是整个方向图的严格误差界，更不是
与全波或实测结果的误差界。

初始入射口采样在 (az,el)=(26.5°,24°) 处曾得到14.97 dBsm孤立尖峰，
但随网格变化大幅跳动。最终出射口方法在该点随加密收敛至约9.77 dBsm。
该伪峰及其他同类点已经通过重新积分修正，没有对最终图做平滑、删峰、
插值补峰或用解析公式覆盖数据。比较见 entrance_exit_sampling_comparison.csv。
此前经过验证的正向19.47 m^2结果不受此问题影响。

图示约定
热图颜色为绝对 RCS（dBsm），黑色等值线为相对正向−3 dB。
二维/三维色标下限−25 dBsm，低于它的数值只在显示上截色，原始数据未截断。
三维图的半径为 sqrt(sigma/sigma_max)，颜色仍为绝对RCS；x/y/z轴为
归一化方向图坐标，不是反射器的毫米尺寸，也不是以dB值作为几何半径。
局部切面图的纵坐标显示下限为−35 dBsm。

模型边界
三板理想导体PEC、零厚度、严格正交并连接；自由空间远场、单站。
属于 SBR/GO + 孔口场积分高频近似，非全波。
未加入显式 UTD/PTD 物理边缘绕射、金属损耗、表面粗糙度、装配误差或支架。
孔口积分自身包含有限孔径相干干涉，不能据此宣称已包含完整物理边缘绕射。
接近掠射的增强、弱瓣和深零点应结合这些近似限制解读。
